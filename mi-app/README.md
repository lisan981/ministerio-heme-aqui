# Mi App - Lista de Tareas

Una aplicación web simple para gestionar tareas (ToDo) con filtros y persistencia en `localStorage`.

## Ejecutar

- Abre el archivo `index.html` en tu navegador.
- No requiere servidor ni instalación de dependencias.

## Funcionalidades

- Agregar, completar, editar (doble clic) y eliminar tareas
- Filtros: Todas, Activas, Completadas
- Contador de pendientes
- Eliminar todas las completadas
- Persistencia con `localStorage`

## Atajos y tips

- Doble clic en el texto de la tarea para editar
- Enter para agregar una tarea

## Estructura

- `index.html`: Estructura y UI
- `styles.css`: Estilos (claro/oscuro por preferencia del sistema)
- `app.js`: Lógica de la app
